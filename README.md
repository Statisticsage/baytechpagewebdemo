## How to Use

**Option A: Download one file**
1. Click any Live Preview link above
2. Go back to the repo and click the `.html` file
3. Click the **Raw** button
4. Right-click, choose **Save As**, and save it as `index.html`
5. Open it in your editor and replace the placeholder text with your info
6. Deploy to GitHub Pages, Vercel, or Netlify (all free)

**Option B: Clone the whole repo**
```bash
git clone https://github.com/Statisticsage/baytechpagewebdemo.git
```

## Adding a New Demo

1. Upload the new `.html` file to this repo
2. Open `index.html` and copy one line inside the `DEMOS` list
3. Change the name, type, file name and description, then commit

The gallery updates itself.
